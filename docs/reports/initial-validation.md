# 首版实现验证记录

日期：2026-10-27。范围：本地 Python 标准库运行器、会话宿主 skill、资产生命周期与可分发包。

项目独立位于 AstroFairy。借鉴单源、自动门禁、测试归属及 guides/adr/reports 分层，
未接入 AstroProject 的包注册、同步、机器配置或 issue tracker。
开发工具安装在本项目虚拟环境，版本单源为 requirements-dev.lock。
没有提交、推送、发布或安装到全局 skill 目录。

## 自动验证

本次实际运行覆盖：命令边界、真实文件写入、原始附件快照、检查来源与版本、冲突显式处理、
调用预算、结果未知、重启恢复、并发序号、字节与事件完整性、候选隔离、精确资产验证、
基准变化、版本钉选、分享导入、正面反馈回流及便携 skill 隔离启动。

统一入口：`python dev/check.py`。Ruff 保留 ALL 选择集，差异逐项说明；mypy 保留
warn_return_any；无运行时第三方依赖。包构建和 skill 前置结构检查单独执行。

实际结果：42 项运行器与库测试、1 项便携 skill 隔离启动测试全部通过；Ruff、格式、mypy、
文档引用、测试面与增长预算检查通过。skill-creator 的结构验证通过。

## 独立前向试用

使用全新上下文的独立执行者，输入为测试方提供的虚构会议材料和一句自然语言需求。
执行者获得 skill、原始材料和限定写入目录，没有预期答案或缺陷提示。

1. 首次任务：自主整理一页行动简报，生成 PDF、可编辑 Word 和 receipt。
   实际检查 PDF 页数、提取文字、查看渲染图；未要求用户设计结构。
2. 测试方提供明确标注的合成正面反馈，要求沿用并便于同事复用。
   执行者记录反馈，建立独立维护任务，提炼工作流，经验证后采用为 trial，导出本地分享包。
3. 第二次任务：提供不同人物、预算和事项；执行者搜索命中并读取工作流的精确版本，
   生成第二份单页 PDF，检查本次事实且排除原任务事实残留。receipt 实际记录资产引用。
4. 接收端：在全新状态目录仅使用分享包导入，重新执行本地验证并采用为 trial，实际搜索、
   读取成功，未读取发送方数据库。宿主发现一项辅助检查带入旧上下文后，废弃该检查，
   保留历史并补做仅依包内材料的验证。此项失误与补正均有原始记录。

全部原始过程与产物保留在本地忽略目录 `.evaluation/forward-test/`。
这是合成输入的前向试用，不是团队实际采纳或独立认证语义正确性的证明。

从任务创建事件到首次关闭事件：首份简报约 125 秒，第二份约 64 秒；维护分享约 114 秒，
资产验证约 15 秒。这不包含创建前的准备时间，也不是同任务对照的性能基准。

## 试用发现与修正

- 返回 workspace 时目录不存在：创建任务时即准备工作目录，并补回归检查。
- 捕获文件默认缺具体 MIME：依据标准库文件名类型推断，并保留显式指定；不据此宣称文件有效。
- 调用失败但 CLI 返回 0：失败、未知及未通过机械检查返回非零，保留真实结果记录。
- 新反馈未进入旧 receipt：关闭任务接收反馈或迟到报告后，刷新交付投影。
- 候选读取入口不清楚：说明通过验证任务的内容引用读取；候选仍不进入普通使用路径。
- 资产采用标准可能被策略改写：固定采用策略准则，并检查完整准则与精确包的一致性。
- 导入时只保留包来源会丢失经验理由：保留发送方声明的证据说明，归属于 bundle 来源，
  不将其升级为接收端实际观测；分享导入回归检查已覆盖。

wheel 与 sdist 构建通过；wheel 在隔离安装目录实际导入并建立任务成功。
便携 skill 带入运行器，无需额外安装运行包；其隔离启动由开发测试实际覆盖。
CI 配置已建立，actions 引用通过官方 GitHub 发布与 tag 查询取得并钉为 commit；尚未推送运行远端 CI。

## 边界与后续

首版采用协作式会话宿主，未实现绕过宿主工具的强制沙箱、模型 API 托管或常驻后台调度。
调用次数与内容读取有本地预算，真实模型 token 和墙钟时间由宿主管理。
语义质量由明确标注的模型判断承担；本地工具回执只证明对应操作实际执行。
结果未知会阻断完整完成，任意外部动作的自动对账恢复尚未实现。
个人/team 是本地命名空间；共享为文件包，未实现远程账户权限。
单次正式交付有一个主成果与 receipt，附加产物可通过工作区或组合包提供。
全部边界见[架构](../guides/architecture.md)，不以本次测试声称永久完备或最优。
