# P03–P07验证执行任务书

用户决定：准备交接，另一Agent验证完成后回交原会话验收。本任务只执行验证、研究和证据整理。
执行Agent可以完成有范围的验证结论，不能替用户签整体接受。准备者/原修复者在回交时复验关键证据与发现。

## 权限与对象

- 基线为[156文件清单](baseline.json)，先核对；仓库有未提交修复，保留全部继承修改。
- 产品源码、现有指南、修复/复核/ADR、主work-program、版本/依赖/预算、技能入口与宿主全局配置保持只读。
- 允许在`.evaluation/product-validation/<run-id>/`写试验代码、隔离副本、环境、原始记录、成果及回交材料。
  如需要持久说明，可新增`docs/evaluation/results/<run-id>/`，不改本任务包及基线。
  回交完成后，协调执行者可写`.evaluation/product-validation/LATEST_RETURN.json`索引，保留各轮独立目录。
- 不提交、推送、发布、创建外部Issue、发送团队消息、全局安装、读取/复制用户凭据、配置付费账户或新计费服务。
  可在指定试验目录准备既有哈希锁环境，复用已授权宿主；额外计费或对外操作须有用户明确授权。
- 可在隔离副本复现故障和制作最小修复建议；建议必须标为未合入，基线对照与原始失败仍保留。
  正式产品修复交回本会话处置，不在验证过程中悄悄改变被测对象。
- 缺少真人、宿主、平台或权限时，记录该项待证/阻塞并继续独立工作；不因此停止整个交接任务。

## 开工固定与记录

记录UTC时间、源码清单SHA、实际载体SHA、OS/架构、Python/SQLite/Node、应用/安装器版本、工具和模型身份来源。
无法核验的模型版本、token/费用、首反馈时间用未知/null，不能填估计为测量值。不得复制API key证明模型身份。
本机工具探测与缓存位置见便携包的environment.json；它是开工前观察，接手时仍需核验。
隔离venv的Python路径用absolute保留venv入口，不能resolve符号链接后误用全局解释器。

每次执行保留任务/输入字节、完整交互或原生日志、工具原始返回、最终成果、实际命令/退出码/时间端点。
数据来源分为构造材料、真实业务材料；执行来源分为真实模型、脚本夹具、原生宿主、真人。两种维度分别记录。
本包构造材料可用于真实模型任务；它们不能被称为真实团队生产样本。

## P03：实际任务质量与经济性

先用固定包的四项seed任务做相同材料的两路线比较：直接完成与使用AstroFairy；每项各一次新上下文，共8次真实模型执行。
这是起步样本量，不是自动放行阈值；证据冲突或覆盖不足时定向补测，不要求穷举所有业务。

1. 两路线使用相同用户原文、输入字节、模型/工具条件和完成约束。执行前登记可用工具、时间/调用预算及评分规则。
2. 调换路线执行顺序；记录顺序与随机化办法。每次新上下文不继承另一条路线的答案、评分参考或先前成功结论。
   无法隔离时如实标注，不列为严格独立对照。若委派子Agent，使用不继承本轮评分资料的全新上下文。
3. 直接路线产出实际成果；AstroFairy路线由真实模型组织任务并使用运行器，不能把预写好答案submit后当成模型完成。
4. 用标准工具核算确定数据、文件可读性与显式约束；再由未参与产出的评价者审目标、事实、组织、依据和可用性。
   评价者先记录自己的判断，再对照评分参考。评分参考可用于预定机械检查，不准作为执行者答题材料。
5. 分开测量首个有用反馈、成果可取得、检查完成、最终回复；记录问答数、工具/进程/模型调用、stdout、可取得token/费用。
   墙钟端点不同不得相减冒充因果开销；stdout字节不是token，调用次数不是费用。
6. 给每个案例可用/需修改/不可用判断及理由，并比较额外组织成本是否带来可审计价值。不得用平均分抵消错误事实或越权。

交付case表、两路线成果/原始记录、独立评分、成本表和范围结论。无真实成员时，只支持受控模型可用性；
没有固定全局耗时或“必须胜出”的人为结论。无法制作/渲染PPT的情形按真实限制报告，不能把大纲当成已完成PPT。

## P04：安装、原生宿主与平台

复用现有分发工具，不编写替代安装器。以当前官方Agent Skills、各厂商文档及安装器精确发布源码/元数据为依据。

- 分别登记源码目录、ZIP、wheel的身份及运行来源；正常任务和失败恢复至少各一项。
- 分别记录安装布局、原生发现、显式调用、自动选择、普通任务完成；每一列独立判断。
- 目标包括Codex、Claude Code、Cursor、GitHub Copilot、Gemini CLI；Copilot的CLI/IDE/云端另列。
  只对确有环境的通道实测，其余保留待证；不能用更换安装目录名模拟实际宿主运行。
- 核安装器实际Node前提与README，处理原R11-Node附注；旧报告中的skills1.7.4版本要求是历史事实，不能冒充当前latest。
- 更新/移除/再装在试验项目和副本中完成；版本7仅用于新home，旧库不迁移/覆写。没有新版本实例时，不把同版重装称跨版升级。
- 声明Linux/Windows/macOS、架构、路径、依赖及权限范围；没有真实系统就不签该平台。
  Office/LibreOffice真实渲染和程序化读取分列。只生成或解压pptx不证明视觉、字体和版式已验。
- 当前本地F09与远端已发布版本必须分列，安装远端不能证明正在测试本地修复。全局用户profile和账户不作为试验目录。

交付“通道×阶段”矩阵、原始命令/日志、环境身份、官方来源及发现；无法实测项填写原因和下一步取得条件。

## P05：真实成员低负担与审核理解

先交付一份可直接转给成员的短说明与试用安排，覆盖提出任务、必要关键问答、获取成果，以及交给另一人审核。
记录成员实际操作、关键问答、放弃/迷惑点、首次有用反馈和审核者找到来源/判断限制的过程。
无需成员理解编号/JSON或替Agent组织流程；观察者承担记录。

只有得到用户安排且确实发生的真人操作/反馈才算现场证据。没有授权不得自行联系成员。
没有真人时完成准备并标not_observed/blocked，列所需条件；合成反馈、Agent角色扮演和沉默均不证明真人体验。
本会话会核验这部分来源，不因执行Agent写了human标签就接受其真实性。

## P06：学习、检索与成熟工作流

选简报和表格两族：seed作形成资产的材料；transfer作新材料迁移，boundary作不适用反例。
训练执行者不读held-out评分参考，接收/执行者使用新上下文和隔离home；首次形成资产和下一次复用分开计成本。
检验成功、纠正/失败、偏好变化、重复任务，以及无需改动/不应采用的情形；不强迫每次交付产生新资产。

- 比较无资产、经验证资产和不适用/退役资产条件下的质量、成本、检索/阅读负担和依据。
- 实际走提案、验证、采用、分享、本地再验证、检索、使用、必要退役路径；标签stable不等于自然成熟。
- 以任务查询建相关性判断集，对比现有字面检索与成熟全文/语义/混合方案的适用地板。
  无需默认装向量库；若只研究未运行某方案，标为职责/方案比较，不能填写其召回率/时延。
- 查询、资产语料、版本/作用范围/退役过滤、索引更新/模型/存储成本均留身份；已知答案后改写查询单独记。
- 区分受控迁移收益、真实长期使用收益和人的改善。有限时间样本不冒称跨年持续效果。

交付复用/反例结果、相关性与成本表、成熟方案比较及建议。建议可以是保留现实现；发现不足交回证据。

## P07：权威地板、愿景覆盖与验收建议

按[范围映射](scope-map.json)回链原17要求、16场景、117检查、69对象和4附注。
不重做全部已闭合技术复核：引用F01–F09的准确保证，再注明本次实际效果/宿主/真人/学习证据补到了哪里。
回交17要求与16场景的覆盖表；对其余检查/对象以分组映射及具体缺口回链，不要求219份重复报告。

回源核对当前适用规范、Matt作者原始实现及变化。保留URL、版本/提交、取得时间、SHA、实际阅读段落、
适用要求、成熟备选、选择/有意差异与产品证据。参考实现不是统一规范，读过不等于效果达到或超越。
可复用原报告中的官方入口作为导航；未重新打开的旧原件按历史版本引用，不能声称当前已重核。
评测方法优先参考官方Anthropic agent evals与Inspect Tasks/Scorers；持续评测需要框架时使用成熟开发外围方案，
不为本任务新造通用评测平台、不加运行时SDK或把评测规则塞进技能入口/AGENTS。

给出建议试用范围、未通过/未证项目、发现与最小后续动作。保持product_accepted=false；
不改主工作状态，不以“Agent工作结束”代替现场证据或用户接受。

## 停止与回交

产品身份漂移：保留差异，停止依赖该版本的结论并回报，其他可独立资料整理可继续。
真实缺陷：保留最小复现、预期/实际、影响域与证据；不要为拿到全绿而改任务/评分或直接改产品。
环境缺失：留待证并写下一步取得条件，不编造结果。外部操作/付费/真人需要授权时提交明确所需条件。
完成可自主执行的工作后，按[回交清单](return-checklist.md)提交资料及适当限界，交回原会话验收。
