# 实施、验证与收敛

方案设计完成不代表下表实现已经执行。每个工作包交付可审查变更及影响域验证，保持历史原件，
不提交或发布，直到维护者明确授权相应动作。开发无旧协议兼容路径。

## 依赖与工作包

| 工作包 | 前置 | 必须产出 | 验收门 |
|---|---|---|---|
| W01 目标合同与单源 | 方案技术检查完成 | 新协议 Schema、内容/成员/快照/准则靶标、资源 profile；保留不变量 | 同摘要双文件、必要成员、当前/历史判断、候选精确绑定的正反例 |
| W02 内容与交付闭环 | W01 | 流式捕获、集合发布、作用域检查、BagIt 完整导出和回执 | 原多文件症状消失、失败不能洗白、损坏/中断/并发无混合成功 |
| W03 可执行主文与阶段工作包 | W01/W02 接口稳定 | fairy 唯一入口、完整常规示例、具体载荷、prepare-delivery、首用/恢复路径 | 实际宿主首任务、续用、修订、长资料与中断对照；区分已加载/已读/已执行 |
| W04 检索与学习投影 | W01 | 本地混合索引、固定模型/profile、结构切分、代次同步、适用判断和学习决定 | 正文/中文/同义等查询、状态过滤、迟到变更与重建；不把找到当采用 |
| W05 资源校准与保护 | W02–W04 有可运行路径 | 43 项处置落实、测量报告及冻结默认，真实费用/时间取得性说明 | 正常任务不被小额阻断，异常量/锁/截止/配额均显式且可恢复 |
| W06 净收益与行为验收 | W03/W04/W05 | 封存查询、对照任务、真实模型轨迹、适用/拒用/不变案例 | 如下有限矩阵与门槛；差异按真实证据解释 |
| W07 恢复/分发/文档 | W02/W04/W05 | 所有历史成员审计、备份恢复、派生索引重建、核心/检索/模型锁、标准 wheel/skill 包 | 新环境精确安装及主要宿主原生任务；文档只声称实际通道 |
| W08 独立复验与发布准备 | 前述相关门完成 | 影响域独立复验、问题闭合、更新项目说明/README与 release notes | 无已知阻断；维护者批准发布后才提交/推送/打标签 |

W03 与 W04 可在稳定合同后独立推进；不以未完成长期真人观察阻断有限技术改进。
任何接口/语义变化沿依赖边重验，单纯参数校准不把所有历史工作推回起点。

## 实测门与停止条件

- 行为对照至少覆盖普通文字成果、多文件材料任务、修订和恢复；相同宿主/模型/权限/材料，
  记录实际加载、读取、动作、首个有效反馈、总时间与人类干预。随机偏差通过有限重复检查，
  不以四步口头复述或 receipt.complete 当作遵循率。
- 检索先封存代表性语料/标注和调参与留出查询，至少覆盖 V16–V19 的全部类别。比较字段范围
  一致的全文、向量、混合及当前基线；再单独比较加入正文的收益。默认 profile 的留出 Recall@10
  目标不低于 0.90，nDCG@5 不低于成熟全文对照；若语料相关项少，按实际可达上限报告。
  状态/权限/退役过滤必须无已知错误。阈值是产品验收目标，不是外部标准规定或统计总体承诺。
- 近似但不适用/无合适方法的情形另评，不让召回指标掩盖误用；记录真实使用/拒用和任务结果。
  不用人为向量或模型目录存在替代这些门。
- 学习至少完整跑通一个方法形成与再使用、一个修订、一个拒用/退役和一个不变路径；比较形成
  成本与后续净收益，保留语义判断来源。团队长期传播和人的进步继续观察，不编造短期证明。
- 性能分别记录冷准备、首查询、热查询、总任务与维护，不把通知片段、缓存 token 或文件mtime
  混成实际首反馈和账单。对正常任务出现明显退化要定位；不得声称未测平台达标。
- W05 至少覆盖 32/128/256 MiB 文件和多文件总量、长正文/Schema、实际正常调用数量、
  锁竞争和备份增长。初值阻断正常场景、峰值内存不合目标环境或未知效果处理破坏时返工。
- 关键合同、原症状、组合和异常恢复均通过且无未闭合阻断发现时，技术工作收敛。只有新变更、
  失败或新证据才重复相关试验；不为绝对完美扩大无限场景。

## 发布前的“地板”门

直接采用的规范必须由对应参考库/工具和必要正反例实际核验；成熟组件除单独能运行外，
还要完成权限、版本、代次、证据和恢复接线。所有平台、模型与效果声称均绑定实测身份。
若某一强制职责缺实际实现或关键验证，不以“轻量”“临时够用”豁免；限定发布范围须明示，
不能把未完成能力继续写成默认承诺。

核心/检索/模型准备均使用锁定原件；不把本轮探针临时 pip 环境用作最终依赖锁。
发布仍走既有流程及维护者授权，方案批准不自动授予提交、上传或发布权限。
