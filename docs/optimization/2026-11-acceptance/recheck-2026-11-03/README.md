## 检索与学习

**ROOT-01/03 关闭**：带重复块的两路融合与公式一致，固定目录的声明文件 SHA256、tokenizer
同源及离线消费路径已生效；空缓存普通查询拒绝初始化，真实 E5 缓存实际运行通过。

**ROOT-02 仍未关（P1）**：准备时传入的 revision/force_download 被当前锁定 FastEmbed 构造器
丢弃，实际下载层只收到 local_files_only/specific_model_path。已有缓存能正常跑不代表按 pin
准备已接通。HEAD 与 pin 不同会默认取最新后被产品拒绝；同长度字节损坏也得不到所宣称的
强制重下保障。SDK 对部分大小异常本来会重下，不能夸大成所有损坏都无法恢复。

**ROOT-04 仍部分未关（P1）**：结构字段/投影、部分学习决定及手工治理引用已实现；仍欠：

- maintain 创建 child 后，源任务没有决定或 child 链接，`learning.decided` 仍 false。
- defer 后 no_change 仍列旧 todo；新任务看不到旧待办，也缺无需先知 TASK 的发现入口。
- 治理仍依赖 host 先提供 refs；按范围确定候选、固定必需引用、提示未知适用性的接线尚缺。

这不要求脚本代判语义适用性，也不把已有维护子任务/采用/退役机制说成未实现。
profile 的字段清单也应与新增投影语义一致；作为相关修复的身份核对项，不另增阻断编号。
