# AstroFairy 0.1.0a1 · Alpha

2026-11-01 · [English](#english) · [简体中文](#简体中文)

## English

First tagged prerelease of AstroFairy: an Agent Skills package for structured task delivery,
traceable checks and an external library of reusable workflows. The existing agent supplies the
model and specialist tools. This release is available for real-world trial and feedback.

### Included

- A portable skill with progressive references and a bundled Python runtime.
- Revision-bound agreements, captured inputs and artifacts, distinct tool/model reviews and receipts.
- Explicit invocation budgets and uncertain-result handling, including declared authoritative reconciliation.
- Candidate, validation, adoption, revision, retirement and file-based sharing of workflow assets.
- Bounded CLI responses, authenticated selected document reads, shared immutable document blocks,
  full integrity audits, backup verification and restoration into a new directory.

### Installation and artifacts

Use the [installation instructions](../../README.md#install). Requirements include Python 3.12+,
the hash-locked dependencies and a capable SQLite build. The verified skills installer is 1.7.4,
requiring Node.js 22.20.0+; manual copying requires no Node.js.

The release provides `astrofairy.zip`, an optional wheel and source distribution, and `SHA256SUMS`.
The ZIP contains the standalone `astrofairy/` skill folder. Runtime preparation still installs
the bundled locked dependencies. Source version is `0.1.0a1`; generated plugin version is
`0.1.0-alpha.1`; protocol/store format is 7. Older stores are refused without migration.

### Validation and limits

The release check covers 134 runtime tests and 19 development tests, typing, style, Agent Skills
validation, metadata/lock consistency, document references and growth budgets. The existing technical
repair work and independent verification are retained in the [repair records](../repairs/README.md).

Controlled local Linux/aarch64 trials include four task families, eight direct/skill model runs,
Claude Code and Codex use, five copied installer layouts, workflow trials and actual backup recovery.
They support feasibility within those conditions. The [evaluation acceptance](../evaluation/results/acceptance-20261101/acceptance.md)
and [release addendum](../evaluation/results/release-20261101.md) narrow the conclusions and correct
the known measurement and interpretation issues without rewriting original records.

Real-user usability, broad host/platform compatibility, Office rendering, native managed updates,
strict automatic-selection conditions and long-term learning/economics remain unproven. The runtime
does not sandbox the host or independently certify semantic quality. Storage and full-history replay
can grow; no automatic garbage collection is provided. Host tokens and elapsed time are not locally
hard-capped. Some simple tasks cost more with the workflow; universal superiority is not claimed.

The maintainer authorized this scoped alpha release. That release decision does not declare the
entire P03–P07 evaluation program complete. Future work is guided by observed issues and real use.

## 简体中文

AstroFairy 首个带版本标签的预发布：遵循 Agent Skills 规范，帮助现有智能体有序完成任务，
保留检查依据，并将可复用方法放入外置工作流库。本版开放实际试用与反馈，模型及专门工具由宿主提供。

### 本版能力

- 便携 skill、按需加载的参考文档和随包运行器。
- 绑定修订的任务约定、材料与成果留存、区分工具观测与模型判断的检查及回执。
- 显式调用预算、未知结果处理，以及由工具声明的权威核对机制。
- 工作流资产的候选、验证、采用、修订、退役与文件分享。
- 有界命令回包、经完整性验证的文档选读、不变内容共享、完整审计及备份验证与新目录恢复。

### 安装与附件

见[安装说明](../../README.zh-CN.md#安装)。需要 Python 3.12+、锁定依赖和具备所需能力的 SQLite。
本次验证的 skills 安装器为 1.7.4，要求 Node.js 22.20.0+；手动复制不需要 Node.js。

附件包含独立 skill 的 `astrofairy.zip`、可选 wheel、源码包及 `SHA256SUMS`；运行前仍需准备随包锁定依赖。
源码版本为 `0.1.0a1`，派生插件版本为 `0.1.0-alpha.1`，协议及存储格式为 7。旧数据库不迁移、不兼容。

### 验证与边界

发布检查覆盖 134 项运行器测试、19 项开发测试，以及类型、风格、Agent Skills 结构、元数据与锁、
文档引用和增长预算。已有技术修复与独立复验保留在[修复记录](../repairs/README.md)。

本地 Linux/aarch64 受控试验包含四类任务、八次直接/skill 模型执行、Claude Code 与 Codex 使用、
五种复制安装布局、工作流试用和实际备份恢复。它们支持相应条件下的可行性。
[验收意见](../evaluation/results/acceptance-20261101/acceptance.md)与
[发布补充说明](../evaluation/results/release-20261101.md)记录结论范围及计量、解释修正，原始记录不改写。

真人易用性、广泛宿主与跨平台支持、Office 渲染、原生托管更新、严格自动选择条件和长期学习/经济收益仍待观察。
运行器不隔离宿主，不独立认证语义质量。存储及全历史重放可增长，没有自动垃圾回收；宿主 token 和总耗时
不受运行器硬限制。简单任务可能增加成本，不承诺普遍优于直接执行。

维护者已授权在上述范围内发布 Alpha；该发布决定不等于 P03–P07 全部完成。
后续依据实际问题与真实使用反馈推进。
