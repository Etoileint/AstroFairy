# F05：包版本到插件版本的规范转换

[ADR-0007](../adr/0007-package-to-plugin-version-contract.md)。执行者 root，独立核验者
f05_independent_verifier，终局裁定者维护者。

## 根因与实现

原生成器直接复制正则捕获的数字文本，既保留非法前导零，也会接受 Unicode 数字；生成后字节一致并不能证明目标语法正确。
现在用已有开发依赖 packaging.Version 读取 PEP 440 含义，再用解析出的整数和规范预发布标记构造 SemVer。
三段 release、epoch 零、可选 a/b/rc 是明确支持范围；post/dev/local、非零 epoch、过短/过长 release 和非法输入拒绝。
支持范围内的标准等价拼写按同一路径规范化，无手写 PEP 440 解析器、零裁剪分支、额外 SemVer 或运行依赖。

仍保留单 literal 版本源与 setuptools dynamic attr；render 在任何消费者写入前完成，check 继续只读，原源文字不被改写。
非字符串 literal 显式 TypeError，非法字符串由成熟解析器拒绝，不支持的合法版本显式 ValueError；失败不会更新派生文件。
稳定版和预发布次序在所支持域内保留：alpha、beta、rc、final 以及数字计数对应原语义。

也比较过把权威版本移到静态 project.version 并生成运行版本文件。独立普通构建反例证实：未先生成时可能得到新 METADATA
配旧运行版本，补齐需要额外构建机制或同步前提。本批保留已有成熟动态来源，避免为这项修复引入新漂移边界。
不声称支持任意 Python 版本声明或所有 PEP 440 形式。当前版本、当前三个派生消费者保持原字节，没有升版、兼容或迁移分支。
