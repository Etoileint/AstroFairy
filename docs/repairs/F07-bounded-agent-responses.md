## 边界与实现

独立基线从现行源码重现多种合法增长：多次补充、完整约定、待处理调用、检查理由、大输入和大工具结果。
单字段字符数限制也挡不住最终 JSON 转义放大。另证实合法超过 16 MiB 的结果可被记录和交付，
但旧学习路径把完整检查快照塞进普通 blob 会失败。这些事实没有被提升为已观察到的宿主超窗或真实质量下降。

本批以统一展示层约束全部 CLI JSON 回包，包括换行和转义。小值直接返回，大值明确返回控制信息与完整文档地址；
原生 Python Workshop 值和执行事实保持完整。文档以原值和任务作用域共同寻址，免费只读路径按标准 JSON Pointer
选择部分，再按完整回包实际字节分段。使用哈希锁定的成熟 python-json-pointer，不重写标准定位解析器。
工具调用预算、质量规则和事实来源没有因展示而放宽。学习保存完整源历史文档，仅把小型目录作为维护输入。

新展示模块与 CLI 同属传输适配职责，不准写任务事件或准入操作；没有把旧核心职责挪出去规避预算。
控制核心仍在原四文件预算内；技能入口不增加人工管理步骤。协议和存储格式 5，开发期直接拒绝旧库。

这些是协议夹具，不冒称真实成员或原生宿主效果。

首次新测试有两处夹具缺少规范要求的 schema 方言，产品正确拒绝；改用已有规范夹具后通过，原失败日志保留。
