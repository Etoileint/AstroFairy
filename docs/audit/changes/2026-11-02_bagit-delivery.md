## 实现与影响

采用官方 bagit 1.9.0 sdist 和固定隔离构建链生成标准 wheel；原件、构建命令/版本和输出 SHA256
登记在 `dev/vendor/bagit-1.9.0/manifest.json`，技能分发副本与 `requirements-delivery.lock`
绑定同一摘要，`dev/check_vendor.py` 在开发检查中复核。`doctor` 增加 `delivery.ready` 状态。

- `_delivery.py` 承担 BagIt 生成、完整校验、私有暂存、原子发布和回执/说明；交付目录为
  `deliveries/<task>/<seq>/`，同序号幂等重验，迟到事实新序号目录，旧交付不覆盖。
- 交付使用原生 file lock 串行；载荷/标签损坏、缺文件、多载荷文件、额外标签文件、符号链接
  和生成失败均拒绝，不发布混合状态；无快照关闭生成空载荷但有效的 BagIt。
- `Store` 增加 `put_file`、`length`、`copy_to_file`：1 MiB 流块、`blobopen`/`zeroblob`、私有
  临时文件和完整摘要复核；单内容 256 MiB、任务唯一内容 2 GiB，超限明确拒绝。
- 初始附件在事务内流式捕获；文件捕获/文本写入/模型报告进入同一任务聚合边界；观察与发布
  使用存储长度，不整文件读取取字节数。
- 审计/备份/恢复继续覆盖全部历史快照与成员引用；新增多快照多成员恢复后重新交付的正例。
- 协议/存储格式仍为 9；没有旧目录布局兼容、迁移或双路径。
